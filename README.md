MB AI SOLUTIONS
Transformamos negocios con Inteligencia Artificial.
Sitio web oficial de MB AI SOLUTIONS — empresa de tecnología e IA que convierte negocios tradicionales en negocios inteligentes mediante agentes inteligentes en WhatsApp, automatización de procesos, integración de sistemas y software a medida.
🚀 Servicios
Agentes inteligentes en WhatsApp — atención 24/7: responden preguntas, agendan citas, toman pedidos y hacen seguimiento.
Automatización de procesos — eliminamos tareas repetitivas: recordatorios, seguimiento, reportes.
Integración de sistemas — conectamos WhatsApp, planillas, pagos y CRMs en un solo flujo.
Asistentes internos con IA — tu equipo consulta inventario, precios y disponibilidad en segundos.
Software a medida y SaaS — del MVP funcional al producto escalable.
🛠️ Stack tecnológico
HTML5 · CSS3 · JavaScript (vanilla, sin frameworks de build)
GSAP 3 (ScrollTrigger + MotionPathPlugin) — animaciones sincronizadas con el scroll, incluido el vuelo del colibrí por la página
Lenis — smooth scroll con inercia
tsParticles — partículas ambientales y estelas de luz

▶️ Cómo ejecutarlo en local
Con VS Code + extensión Live Server: clic derecho en index.html → Open with Live Server.
O con cualquier servidor estático:
npx serve .
# o
python3 -m http.server 8000
